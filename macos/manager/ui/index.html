第一次使用桌面应用

Codex：设置 → 连接 → 启用 ccen，选择服务器里的项目文件夹。以后直接打开该项目。

Claude：点击上方按钮，在桌面应用登录订阅账号，确认 ccen 连接并选择项目。无需命令行授权。

断开服务器？

这会断开两个桌面应用使用的 CCEN 通道。本机浏览器守卫继续运行。

把 AdsPower 接入守卫

在 AdsPower 中编辑需要接入的环境，将代理设为 HTTP，主机 127.0.0.1，端口 17899，账号和密码留空。

保存后重新打开环境，并关闭该环境的 WebRTC 与 QUIC。守卫管理经过它的代理连接。
