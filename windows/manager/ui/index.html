把 Claude 环境接入守卫

在 AdsPower 中编辑用于 Claude 的浏览器环境，将代理设为：

代理类型HTTP
代理主机127.0.0.1
代理端口17899
账号 / 密码留空

保存后重新打开该环境。该环境的网页流量将经过固定住宅出口。已有标签页需要重新连接后才受守卫保护。

请关闭该环境的 WebRTC 与 QUIC。守卫仅管理经过它的 TCP 流量；停止守卫后，该环境应无法联网。
